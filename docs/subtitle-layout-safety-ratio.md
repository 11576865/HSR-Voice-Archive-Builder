# HSR 布局安全区、比例与时间预览

叠加在 PR #133（依赖 #132）上，不新增一套工作台或字幕数据状态。

* 单一 `SafeArea`：默认 1920×1080 画面中水平 3%、垂直 5%。仅用于布局度量的安全估算，**不是 libass 字形像素边界**。
* 布局矩形默认隐藏，可在「画布与诊断」中开启。原文/中文字幕显式 `\pos` 且自行插入 `\N`，ASS Style margin 清零，避免额外作用第二组安全边距；Archive HUD 仍保留其自己的 margin。
* `primary_region_ratio` 默认 0.60，UI 20–80%，划分安全区高度扣除中央 gap 后的可用空间；不改变字形字号比例。FastAPI 和 Termux Lite 保存，项目配置恢复、浏览器几何预览、实际导出共用一个参数。
* 宽度碰撞使用与断行相同的已解析字体路径，避免度量来源不同。
* Karaoke 时间百分比可从 0–100% 定位，松手请求 FFmpeg/libass 对应时刻的**真实帧**，沿用已有过期请求身份防护。并非连续视频播放。
* `tests/test_subtitle_ratio_safety.py` 检查默认与非默认坐标、ASS 参数贯通、无重复样式 margin 和 UI 入口。

**未完成**：实际 libass 字形边界提取、描边/阴影/动态效果全时段越界及碰撞证明、目标 Android 设备验收。这些不能由几何求解器绿灯替代。合并顺序 main → #132 → #133 → 本改动。
