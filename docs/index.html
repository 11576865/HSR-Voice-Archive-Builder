Windows

下载项目后运行批处理文件；不需要手动输入启动命令。

打开仓库 下载 ZIP
Repository github.com/11576865/HSR-Voice-Archive-Builder 查看
01 · GET

获取项目

从 GitHub 下载 ZIP 并解压，或使用 Git 克隆仓库。Git 只在需要 clone / pull 时使用。

02 · REQUIRE

准备环境

需要 Python 3.11+。FFmpeg 需加入 PATH 才能执行音频构建；控制台本身仍可启动。

03 · RUN

启动控制台

双击或运行项目根目录中的：

run_windows.bat
run_windows.bat 会检查 Python、安装缺失依赖并启动 127.0.0.1:8765；启动器默认也会自动打开浏览器。

Android / Termux

使用 Termux 原生工具链；首次安装与日常启动分开。

打开仓库
FIRST INSTALL
pkg install -y git
cd ~
git clone https://github.com/11576865/HSR-Voice-Archive-Builder.git
cd HSR-Voice-Archive-Builder
bash run_termux.sh
DAILY START
cd ~/HSR-Voice-Archive-Builder
git pull --ff-only
bash run_termux.sh
Setup脚本检查 Python、FFmpeg、7-Zip 与轻量依赖，缺少时自动安装。
Runtime启动 dependency-light 的 stdlib server；浏览器访问 127.0.0.1:8765。

Windows 其他启动方式局域网 / 端口 / 更新⌄

局域网控制运行 run_windows_lan.bat；它会绑定局域网地址并输出带随机 token 的访问 URL。默认端口 8765 被占用时，可运行 python -m app.launch --port 8766。

使用 Git 获取项目时，可在启动前执行 git pull --ff-only 更新仓库。
