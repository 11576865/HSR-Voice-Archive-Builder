HSR Voice Archive Builder

把碎片化角色语音整理为连续 FLAC、中英时间轴、字幕与可复查 manifest。这个网页长期存在；真正的解压、哈希、FFmpeg、更新检查和文件生成仍由你的设备完成。

进入本机控制台 查看 GitHub 仓库

Android / Termux：一键复制命令

网页不能直接替你执行 Termux 命令，但可以把完整命令一次复制到剪贴板。打开 Termux 后长按粘贴并回车即可。

日常启动

已经安装过项目时 
cd ~/HSR-Voice-Archive-Builder
bash run_termux.sh

正常启动后，保持 Termux 运行，再点击页面顶部“进入本机控制台”。

更新后启动

先拉取最新 main，再启动 
cd ~/HSR-Voice-Archive-Builder
git switch main
git pull --ff-only
bash run_termux.sh

第一次安装

仅首次使用 
pkg install -y git
cd ~
git clone https://github.com/11576865/HSR-Voice-Archive-Builder.git
cd HSR-Voice-Archive-Builder
bash run_termux.sh

怎么用

1. 打开 Termux在上面复制“日常启动”或“更新后启动”的命令并粘贴执行。
2. 等本地引擎启动终端应显示 127.0.0.1:8765，不要关闭 Termux。
3. 进入控制台回到这个页面，点击“进入本机控制台”。

手机 / 平板控制电脑

在电脑运行 run_windows_lan.bat。终端会显示一个带临时 token 的局域网地址，例如 http://192.168.1.20:8765/?token=...。在同一局域网中的手机或平板直接打开终端给出的地址即可。

GitHub Pages 不保存这个 token，也不代理音频。局域网控制时，音频处理和输出仍发生在电脑上。

为什么网页不能直接启动 Termux

普通网页没有执行 Android shell 命令的权限。这里采用“静态网页负责复制命令，本地 Termux 负责执行”的方式，避免给网页额外系统权限，也不依赖后台服务器。

当前处理原则

Browser UI, local-first processing. 原始 WAV、FLAC、7z、LAB 与最终构建文件不需要上传到 GitHub Pages。GitHub Pages 只负责固定入口、说明和复制命令。
