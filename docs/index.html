GitHub Pages 入口 · 本地优先处理

HSR Voice Archive Builder

把碎片化角色语音整理为连续 FLAC、中英时间轴、字幕与可复查 manifest。这个网页只提供稳定入口与说明；真正的解压、哈希、FFmpeg、翻译和文件生成仍由你的设备完成。

进入本机控制台 查看 GitHub 仓库

怎么用

1. 启动本地引擎Windows 运行 run_windows.bat；Android / Termux 运行 ./run_termux.sh。
2. 打开固定入口以后可以直接收藏这个 GitHub Pages 页面。
3. 进入控制台点击上面的“进入本机控制台”，工作页面运行在 127.0.0.1:8765。

手机 / 平板控制电脑

在电脑运行 run_windows_lan.bat。终端会显示一个带临时 token 的局域网地址，例如 http://192.168.1.20:8765/?token=...。在同一局域网中的手机或平板直接打开终端给出的地址即可。

GitHub Pages 不保存这个 token，也不代理音频。局域网控制时，音频处理和输出仍发生在电脑上。

为什么这里不直接“检测本地后端”

公网 HTTPS 页面主动请求 localhost / 局域网 HTTP 服务，会受到浏览器的本地网络访问权限、CORS 和地址空间策略影响。不同浏览器与版本的行为并不稳定。因此这个入口只做明确的顶层导航，不把“能否 fetch 到 localhost”当成程序运行条件。

当前处理原则

Browser UI, local-first processing. 原始 WAV、FLAC、7z、LAB 与最终构建文件不需要上传到 GitHub Pages。公网页面可以消失，已有本地项目和 http://127.0.0.1:8765/ 仍然能工作。
