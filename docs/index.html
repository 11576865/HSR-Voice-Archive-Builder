日常启动

已安装时，只需要这三行。

TERMUX · UPDATE + START 
cd ~/HSR-Voice-Archive-Builder
git pull --ff-only
bash run_termux.sh
1 · 启动在 Termux 执行上面的命令。
2 · 保持运行看到 127.0.0.1:8765 即可。
3 · 打开控制台返回本页，进入本机控制台。
第一次安装Termux，只做一次 ⌄
TERMUX · FIRST INSTALL 
pkg install -y git
cd ~
git clone https://github.com/11576865/HSR-Voice-Archive-Builder.git
cd HSR-Voice-Archive-Builder
bash run_termux.sh
Windows本机或局域网控制 ⌄

运行 run_windows.bat。需要从手机或平板控制电脑时，运行 run_windows_lan.bat，再打开终端给出的地址。

成品固定输出与可选输出 ⌄

固定核心：连续 FLAC、SRT、manifest、时间轴和构建报告。可选：ASS 字幕、黑屏 MKV。具体状态以本机控制台为准。
