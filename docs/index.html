进度不再藏在任务历史构建、增量定位、下载、合并、AI 翻译与语义检查都会显示当前阶段及已完成数量。

语义偏离改为人工修订往返问题条目集中生成 TXT；可自行或交给智能体只填写 CORRECTION 区域，上传完整文件后从检查点继续构建。
运行报告集中反馈运行时自动展开阶段、数量和错误，成功后自动折叠；成品位置保留在项目区域。
ASS / SRT 与黑屏 MKV同时输出同一时间轴的 ASS 和 SRT；可另行生成只含黑色视频轨与 FLAC 的 MKV，字幕保持外挂，不做耗时烧录。

手机 / 平板控制电脑 处理仍在电脑，本设备只打开局域网控制台 ⌄

在电脑运行 run_windows_lan.bat。终端会打印类似 http://192.168.1.20:8765/?token=... 的地址。手机或平板与电脑处在同一局域网时，直接打开这个地址。

不要把局域网 token 发到公开聊天或网页。GitHub Pages 不保存 token，也不代理你的语音文件。
为什么网页不能直接启动 Termux 这是 Android / 浏览器的权限边界，不是少写了一行 JavaScript ⌄

普通网页没有执行 Android shell 命令的权限。否则任何网站都能在手机上执行任意命令。这个静态页面因此只负责复制命令；真正执行仍由 Termux 完成。

处理原则 Browser UI, local-first processing ⌄

原始 WAV、FLAC、7z、LAB 与最终构建文件不需要上传到 GitHub Pages。Pages 只负责固定入口、文档与命令复制；实际处理由本机 Python、FFmpeg 与原生 7-Zip 完成。
