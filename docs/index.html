Windows 细节首次准备 / 更新 / 端口⌄

安装 Python 3.11+ 与 FFmpeg，并确认 python --version 或 py -3 --version、ffmpeg -version 可用。run_windows.bat 会检查 Python、安装缺失的 requirements.txt 依赖、检查 FFmpeg，然后启动本地控制台。

Git 克隆方式可先执行 git pull --ff-only。8765 被占用时可运行 python -m app.launch --port 8766。局域网控制使用 run_windows_lan.bat，终端会输出带 token 的地址。

Termux 首次安装只做一次⌄
FIRST INSTALL
pkg install -y git
cd ~
git clone https://github.com/11576865/HSR-Voice-Archive-Builder.git
cd HSR-Voice-Archive-Builder
bash run_termux.sh

run_termux.sh 会检查 Python、FFmpeg、7-Zip 和 requirements-termux.txt，然后运行 app.launch --lite --no-browser。
