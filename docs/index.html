星穹铁道角色语音归档工具

把本地语音包整理成连续 FLAC、时间轴字幕和可复现的机器档案。网页只负责说明与进入本地控制台，原始语音和成品都留在你的设备上。

Android / Termux Windows 本地 FFmpeg 增量更新 字幕校对
进入本机控制台 查看安装说明

Termux 日常启动

已经安装过项目时，只需要下面三行。

更新并启动 
cd ~/HSR-Voice-Archive-Builder
git pull --ff-only
bash run_termux.sh
1 · 执行命令在 Termux 中粘贴并回车。
2 · 保持 Termux 运行看到 127.0.0.1:8765 后即可。
3 · 打开控制台返回本页，点“进入本机控制台”。
第一次安装只需要做一次 ⌄
Termux 首次安装 
pkg install -y git
cd ~
git clone https://github.com/11576865/HSR-Voice-Archive-Builder.git
cd HSR-Voice-Archive-Builder
bash run_termux.sh
Windows 启动本机运行或局域网控制 ⌄

本机运行 run_windows.bat。需要用手机或平板控制电脑时，运行 run_windows_lan.bat，再打开终端打印的 token 地址。

项目会生成什么核心成品与可选成品 ⌄

固定核心成品：连续 FLAC、SRT、manifest、时间轴与构建报告。

按需生成：ASS 字幕、黑屏 MKV。

详细能力、增量中文匹配、字幕校对和恢复机制见 GitHub README 与 docs。
