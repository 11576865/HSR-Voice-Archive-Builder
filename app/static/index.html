本地优先与局域网控制

默认地址仅绑定 127.0.0.1。使用 python -m app.launch --lan 时，后端会绑定局域网并生成临时控制 token。手机或平板可以控制电脑处理，但原始音频仍留在电脑。

AI 翻译凭据只保存在处理设备本地。首次配置可运行 python -m app.credentials configure --provider vapi；之后启动器会自动读取，无需每次 export。
